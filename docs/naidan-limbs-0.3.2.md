# 奶蛋婆婆四肢版 0.3.2

这是基于原版 0.3.2 的独立四肢分支，不移动原版标签，不替换原 Release。

## 下载和安装

[发行包](../downloads/naidan-limbs-0.3.2/奶蛋婆婆四肢版0.3.2.zip?raw=true)内只有 `pak08_dir.vpk` 与安装说明。请下载发行包，不要将 GitHub 的整个源码压缩包当成游戏安装包。

1. 完全退出 Deadlock，备份旧奶蛋包。
2. 停用或移走旧奶蛋，避免新旧版本同时加载。使用管理器时，不要同时再手动安装一份。
3. 手动安装到 `Deadlock/game/citadel/addons`；只有确认 `pak08_dir.vpk` 是旧奶蛋时才直接替换。该位置若属于其他模组，请先确认槽位，勿覆盖无关模组。
4. 重新启动游戏。回退时先退出游戏，移除本包并恢复备份。

## 变化与证据

身体/描边在旧导出流程中丢失了 `1/2.54` 的对象尺度，而骨架尺度未变。本版修正四档编译网格的尺寸，保留短粗手和短腿造型。独立脸部、椅子、茶壶及其他几何保持原样。

相机修正恢复了当前零售婆婆的 10 条相机定义和 16 个根骨骼挂点；未采用其他英雄的相机或骨架数据。291 个动作的轨道顺序与动态压缩字段变化后，读取偏移必须重新累计。本版修正了过期偏移，压缩姿态内容保持不变。独立随机轨道读取共 2,703,861 次，修正后与顺序解码不一致次数为零。

700 个包内资源逐项通过独立读取器校验，ZIP 内 VPK 哈希与实机认可版本完全一致。作者于 2026-10-17 反馈当前无明显问题；这不等同于穷尽所有技能、视角与后续游戏版本的测试。
